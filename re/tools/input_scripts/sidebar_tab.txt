# Default front-end timeline plus ESC at 192,000 ms (see esc_skip.txt).
# At 600,000 ms, click the second build tab in the sidebar -- the "$" icon,
# whose rectangle is roughly (516,140)-(552,175) on the 640x480 screen. The
# click is deliberately followed by a move back into the map at 603,000 ms,
# so a frame captured at the end shows the tab state without the cursor over
# it. The clicked tab gains a highlighted border: the sidebar responded.
#
# The map message dispatcher does NOT handle this click: its hit-test
# (0x5cf080) returns 0 for a point outside the map surface, so the
# left-button handler exits at 0x5d0092. The tactical update polls the
# buttons instead -- `push 1; call 0x4f2100` at 0x5cfc76 is
# GetAsyncKeyState(VK_LBUTTON) -- and the sidebar action method
# (0x5f45f0 -> 0x5da0a0, which converts the point to sidebar-local x-0x1e0)
# runs every frame. The build grid itself has no entries in this mission
# state, so there is no build button to exercise; the tab strip is the
# responsive part.
