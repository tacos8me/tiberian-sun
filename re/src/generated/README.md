# src/generated — mechanically derived function bodies

Generated by `tools/gen_bodies.py`. Do not edit by hand; regenerate with `./tools/pipeline.sh`.

Each `.cpp` defines the member functions that its class's reconstructed header declares and that the binary supplies both a function record and a recovered signature for. The signature is copied verbatim from the header declaration, so the file compiles against the reconstructed tree.

A body is a TRANSCRIPTION of the recovered instruction stream against the ts:: machine model in `Machine.h`. Registers, flags, memory and control flow are modelled rather than approximated, so the generated code does what the machine does. Each generated line is one machine instruction and carries the original instruction as a trailing comment, so a file can be read against the recovered listing line for line.

This is not source-shaped decompilation. It is not claimed to be the shape the original source had; it is claimed to be faithful to what the machine does.
